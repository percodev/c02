## Установка
```json
{
	"set" : "pad",
	"pad" : {
		"number" : 0,
		"function" : "input",
		"resource_number" : 0,
		"resource_direction" : 0,
		"normal_state" : "short",
		"debounce" : 50
	}
}
```
## Запрос
```json
{
	"get" : "pad",
	"pad": {
		"number" : 0
	}
}
```
## Ответ (результат выполнения set или ответ на get)
```json
{
           "answer" : { "pad": "ok" },
	   "pad" : {
		"number" : 0,
		"function" : "input",
		"resource_number" : 0,
		"resource_direction" : 0,
		"normal_state" : "short",
		"debounce" : 50,
		"value": 1
	}
}
```
#### Примечание: для изменения функции физ. контакта его сначала надо удалить, а затем передать конфингурацию с новой функцией. Установка новой конфигурации без предварительного удаления контакта приведёт к тому, что функция контакта останется прежней.

Номер физического контакта "number" : 0 — 14

На плате контроллера по группам расположены:

Входы (адресация 0—7):

	[0] - IN1 датчик двери 1 (1-1)
	[1] - IN2 датчик двери 2 (1-2)
	[2] - IN3 датчик двери 3 (2-1)
	[3] - IN4 датчик двери 4 (2-2)
	[4] - DU_A кнопка ДУ
	[5] - DU_ST кнопка ДУ
	[6] - DU_B кнопка ДУ
	[7] - FA вход FireAlarm    
    
Выходы (адресация 8 — 14):

    [8] - L_T1 (NO1/C1/NC1) выход управления ИУ
    [9] - L_T2 (NO2/C2/NC2) выход управления ИУ
    [10] - OK1 выход
    [11] - OK2 выход
    [12] - PU_A выход ДУ
    [13] - PU_ST выход ДУ
    [14] - PU_B выход ДУ


Функция физического контакта "function" :

	`remote_control_input`, `remote control input` — вход ПДУ
	`remove_card_input`, `remove card input` — вход изъятия карты
	`fire_alarm_input`, `fire alarm input` — вход пожарной тревоги
	`pass` — датчик двери / сигнал прохода
	`input` — вход обычный
	`remote_control_output`, `remote control output` — выход ПДУ
	`remove_card_output`, `remove card output` — выход изъятия карты
	`exdev_output`, `exdev output` — выход управления ИУ
	`output` — выход обычный



Номер ресурса (см. функцию), к которому "привязан" физический контакт `resource_number` : 0 — 4

Номер направления ресурса (см. функцию), к которому "привязан" физический контакт `resource_direction` : 0 — 2

Нормализованное состояние физического контакта "normal_state" :

	`short` / `break` - для входов
	`not_powered`, `not powered` / `powered` - для выходов

Антидребезг (для входов), мс `debounce` : 1 — 10000

Текущее состояние контакта `value` : 0 (норма) / 1 (активизирован)

Ошибки "error":

	"DB error" — ошибка записи в БД.
	"Invalid: number" — некорректный номер считывателя
	"Invalid: function" — некорректная функция ФК
	"Invalid: normal_state" — некорректное значение нормального состояния
	"Invalid: debounce" — некорректное значение времени антидребезга
	"Invalid: resource_number" — некорректный номер ресурса
	"Invalid: resource_direction"— некорректный номер направления ресурса
