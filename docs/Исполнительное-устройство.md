
## Установка:
```json
{
	"set" :  "exdev",
	"exdev" : {
		"number" : 0,
		"type" : "turnstyle",
		"opt_fix" : "pass",
		"analysis_time" : 7000,
		"unblock_time" : 7000,
		"opt_mode" : "potencial",
		"opt_norm" : "afteropened",
		"impulse_time" : 250,
		"remove_card_time" : 250,
		"wait_command_time" : 2000
	}
}
```
## Запрос:
```json
{
	"get" : "exdev",
	"exdev": {
		"number" : 0
	}
}
```
## Ответ (результат выполнения set или ответ на get):
```json
{
           "answer" : { "exdev": "ok" },

		"number" : 0,
```

# Параметры ИУ

`number` — Номер исполнительного устройства (ИУ) : 0 — 2

`type` — Тип ИУ : 

	`lock` — односторонний замок
	`double lock` — двусторонний замок
	`turnstyle` — турникет с унифицированным интерфейсом
	`gate` — шлагбаум
 
`opt_fix` — Фиксация прохода : 

	`card` — по предъявлению карты (отсутствие датчика проезда)
	`pass` — по фактическому проходу
    
`analysis_time` — Время анализа карты, мс : 250 – 180000

`unblock_time` — Предельное время разблокировки ИУ, мс : 250 – 180000

`opt_mode` — Режим работы выходов управления ИУ : 

	`potencial` — потенциальный
	`pulse` — импульсный
     
`opt_norm` — Нормализация выходов управления ИУ :

	`afterclosed` — после закрытия
	`afteropened` — после открытия
    
`impulse_time` — Длительность импульса управления ИУ для импульсного режима, мс :  250 – 180000

`remove_card_time` — Время изъятия карты, мс : 250 – 180000

`wait_command_time` — Время ожидания реакции сервера на предъявленную карту, мс : 250 – 180000


# Ошибки "error":

	"DB error" — ошибка записи в БД.
	"Invalid parametr" — некорректное значение параметра  parametr.
	"Required: number" — отсутствует номер ИУ.
