## Установка
```json
{
	"set" : "reader",
	"reader" : {
		"number" : 0,
		"type" : "rs485",
		"port" : 0,
		"exdev_number" : 0,
		"exdev_direction" : 0,
		"server_addr" : "172.17.0.232",
		"server_port" : "1234",
		"login" : "admin",
		"password" : "parol",
		"lane" : 1,
		"motion" : "both",
		"channel" : "sdery7f",
		"ssl" : "true",
		"serial" : "12345"
	}
}
```
## Удаление:
```json
{
	"set" : "reader",
	"reader" : {
		"number" : 0
        }
}
```
## Запрос
```json
{
	"get" : "reader",
	"reader": {
		"number" : 0
	}
}
```
## Запрос всех сконфигурированных считывателей и доступных USB-устройств
```json
{
	"get":	"reader",
    	"reader":	{
    		 "available_devices" : true
    	 }
}
```
## Ответ (результат выполнения set или ответ на get)
```json
{
	"answer" : { "reader": "ok" },
	"reader" : {
		"number" : 0,
		"type" : "rs485",
		"port" : 0,
		"exdev_number" : 0,
		"exdev_direction" : 0,
		"server_addr" : "172.17.0.232",
		"server_port" : "1234",
		"login" : "admin",
		"password" : "parol",
		"lane" : 1,
		"motion" : "both",
		"channel" : "sdery7f",
		"ssl" : "true",
		"request_string" : "/where/we/want/to/get/to",
		"serial" : "12345"
	}
}
```
Если в запросе был параметр "available_devices" : true, то после передачи счит-ля (всех счит-й) будет дополнительный кадр со списком доступных USB-устройств:
Вариант при отсутствии USB-устройств:
```json
{
	"answer":{"reader":"ok"},
	"reader":{"available_devices":[]}
}
```
Вариант при при подключенных сканерах штрих-кода:
```json
{
	"answer":{"reader":"ok"},
	"reader":{
		"available_devices":[
			{"barcode_usb":"SuperLead_4200_76BS100114"},
			{"barcode_usb":"SuperLead_4200_76BS100131"}
			]
		}
}
```
#  Скорость интерфейса OSDP контроллера:
## Установка
```json
{
        "set" : "settings",
        "settings" : {
		"reader_osdp_baud_rate" : "115200"
	}
}
```

## Запрос
```json
{
	"get" : "settings",
	"settings" :  {
		"prefix": "reader_osdp"
	}
}
```

## Ответ (результат выполнения set или ответ на get)
```json
{
	"answer" : { "settings": "ok" },
	"settings" : {
		"reader_osdp_baud_rate" : "115200"
	}
}
```

Номер  считывателя `number`, **int**  : 0 — 32 (прим. условно)

Тип считывателя `type`, **строка** :

	Считыватели PERCo, работающие по проприетарному протоколу PERCo, по интерфейсу RS485:

	`rs485` - для "старых" считывателей без поддержки расширений (перепрошивка, и т.д.)
	`rs485_ir1x` - для "новых" считывателей, поддерживающих перепрошивку.

	Все остальные считыватели:

	`Wiegand`, `wiegand` - считыватель, подключенный по интерфейсу Wiegand
	`osdp` - считыватель, работающий по протоколу OSDP
	`Barcode-USB_terminator`, `barcode_usb_terminator` - сканер штрих-кода в режиме VCOM (с терминириющим символом)
	`Barcode-USB`, `barcode_usb` - сканер штрих-кода в режиме VCOM
	`Barcode-USB_keyboard`, `barcode_usb_keyboard` - сканер штрих-кода в режиме HID
	`trassir` - Trassir - сервер системы распознавания номеров ТС
	`web_server` - универсальный считыватель, работающий по HTTP

_Примечание: `barcode_usb_terminator`, `barcode_usb`, `barcode_usb_keyboard` по сути являются одним типом, допустимо для всех них использовать `barcode_usb` (`Barcode-USB`), контроллер сам определит, в каком режиме работает сканер._

Порт подключения (USB / Wiegand) / адрес на шине (RS-485 / OSDP), **строка** (для установки/запроса допустим **int**) : 0 — 2 (USB / Wiegand) /  0 — 5 (RS-485) /  0 — 8 (OSDP)

Номер ИУ `exdev number`, **строка** (для установки/запроса допустим **int**) : 0 — 1 (прим. условно)

Номер направления ИУ `exdev_direction`, **строка** (для установки/запроса допустим **int**) : 0 / 1

_Параметры для считывателя `trassir` (для считывателей других типов неактуально):_

Адрес сервера `server_addr`, **строка** : `172.17.0.232`

Порт сервера `server_port`, **строка** : `1234`

Пользователь на сервере `login`, **строка** : `admin`

Пароль пользователя `password`, **строка** :  `parol`

Номер полосы движения `lane`, **строка** (для установки/запроса допустим **int**) : 0 — 16

Реверсивное движение `motion`, **строка** :

	`both` — приближение и удаление ТС
	`forward` — приближение ТС (трассир выставляет LPR_DOWN)
	`backward` — удаление ТС (трассир выставляет LPR_UP)

Канал сервера `channel`, **строка** :  `sdery7f`

Использовать шифрование `ssl`, **строка** :  

	`true` - да
	`false` - нет

Строка запроса `request_string`, **строка** : `/where/we/want/to/get/to`


_Параметры для считывателя штрих-кода `barcode_usb` (для считывателей других типов неактуально):_

`serial` - серийный номер устройства, **строка**

`reader_osdp_baud_rate` - скорость интерфейса OSDP на стороне контроллера, **строка**:

	`19200` - 19200 бод
	`38400` - 38400 бод
	`57600` - 57600 бод
	`115200` - 115200 бод
	`230400` - 230400 бод
	`460800` - 460800 бод

Ошибки "error", **строка**:

	"DB error" — ошибка записи в БД.
	"Invalid: number" — некорректный номер считывателя
	"Invalid: port" — некорректный порт считывателя
	"Invalid: type" — некорректный тип считывателя
	"Invalid: exdev_number" — некорректный номер ИУ
	"Invalid: exdev_direction"— некорректный номер направления ИУ
