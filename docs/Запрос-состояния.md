##### `network` — структура состояния сетевых подключений:

`connections` — общее кол-во сетевых подключений, **int**

`hosts` — массив структур, описывающих сетевое соединение:

`10.17.1.130:60090`:`true` — ip адрес и порт хоста. Для входящих подключений порт не указывается (10.17.1.130), для исходящих - адрес и порт удалённого хоста, **строка** : состояние связи, **bool**.


##### `exdev` — структура состояния ИУ:

`number` — номер, **int**

`physical_state` — набор физических состояний ИУ по направлениями, **массив из 2-х строк**:

	`undefined` — не определено
	`normal` — датчик прохода нормализован
	`active` — датчик прохода активирован


`unlock_state` — набор состояний разблокировки ИУ по направлениями, **массив из 2-х строк**:

	`undefined` — не определено
	`lock` — ИУ заблокировано
	`unlock` — ИУ разблокировано
	`break` — ИУ взломано


`access_state` — набор РКД ИУ по направлениями, **массив из 2-х строк**:

	`undefined` — не определено
	`open` — РКД "Открыто"
	`control` — РКД "Контроль"


##### `reader` — структура состояния считывателей:

`port` — порт подключения по шине RS-485/номер контролеера USB (и соответствующего ему разъёма), **int**

`type` — тип, **строка**:

	`rs485_ir1x` — считыватели, работающие по протоколу PERCo-RS-485 (IR13/IR19/IR29)
	`osdp` — считыватели, работающие по протоколу OSDP

	`web_server` — универсальный считыватель работающий по открытому протоколу через http(s)/ws(s)

`model` — модель (для некоторых считывателей), **строка**.

`serial` — серийный номер (для некоторых считывателей), **строка**.

`hw_version` — аппаратная версия (для некоторых считывателей), **строка**.

`fw_version` — версия встроенного ПО (для некоторых считывателей), **строка**.

`server_addr` — IP-адрес считывателя (trassir/web_server), **строка**.

`server_port` — порт считывателя (trassir/web_server), **строка**.

`link` — состояние связи со считывателем, **строка**:

	`link_on` - связь есть
	`link_off` - связь отсутствует

`value` — значение - 0 / 1 (нормализован/активизирован), **int**
